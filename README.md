Meridian Run — a golden-hour flight game over the Meridian islands. Pilot the Kestrel prop plane: take off from Runway One, thread the golden rings, mind your fuel and throttle discipline, and land clean on Runway Two. Three sorties, rising wind and tighter fuel, one sunset.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Arrow keys (or WASD) pitch and throttle, Space pops a flare, the mouse steers as a flight stick, P pauses, M mutes, R restarts.
